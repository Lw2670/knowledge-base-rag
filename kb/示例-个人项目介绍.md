# 示例项目介绍：个人知识库问答系统

## 项目定位

把散落的 Markdown 笔记变成「可对话的第二大脑」。用户用自然语言提问，系统从笔记中检索相关内容并生成带出处的回答。

## 技术亮点

- RAG 四步链路：文档加载 → 分块 → 向量化入库 → 检索生成。
- 检索质量优化：相关性分数阈值过滤 + 按来源去重 + 检索更多再精选。
- 多轮对话：短问题自动拼接上一轮上下文，支持追问。
- 工程细节：索引自动更新、模型可插拔、流式输出、引用来源可展开。

## 量化成果

- 支持任意数量的 Markdown 笔记自然语言问答。
- 答案带出处、可追溯，不凭空编造。
- 从 0 到 1 独立完成，含环境搭建与踩坑解决。
