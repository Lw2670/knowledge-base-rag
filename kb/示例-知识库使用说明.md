# 示例知识库使用说明

这是一个示例知识库，用于演示 RAG 问答系统的效果。你可以直接运行项目，向它提问下面这些问题：

- "这个知识库是做什么的？"
- "番茄工作法是什么？"
- "示例项目有什么亮点？"

## 如何换成你自己的知识库

1. 把 `config.py` 中的 `KB_DIR` 改成你自己的 Markdown 笔记目录路径。
2. 重启应用，系统会自动检测笔记并重建索引。

## 原理

系统会读取目录下所有 `.md` 文件，按 Markdown 标题结构切块，用中文向量模型转成向量存入本地向量库。提问时先检索最相关的笔记片段，再让大模型基于这些片段生成带出处的答案。
