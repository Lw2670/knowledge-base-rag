📚 个人知识库问答系统
GitHub 仓库

把你的笔记，变成可对话的第二大脑

一个基于 RAG（检索增强生成）的知识库问答系统：读取你的 Markdown 笔记，用中文向量检索 + 大模型，回答你提出的问题——答案还带出处，绝不凭空编造。

进入问答系统 查看代码

「进入问答系统」需要先在本机启动服务（见下方快速开始），启动后访问 localhost:8501

它是怎么工作的

1

文档加载

读取知识库里的 Markdown 笔记

2

分块

把长文切成适合检索的小块

3

向量化入库

中文向量模型转向量，存入本地向量库

4

检索生成

提问 → 检索最相关笔记 → 大模型带出处回答

技术栈

框架 LangChain 向量库 Chroma 向量模型 BGE-small-zh 大模型 智谱 GLM-4-flash 界面 Streamlit

快速开始（3 步）

第 1 步 · 配置密钥

把 config.py.example 复制成 config.py，填入你的智谱 API Key。

第 2 步 · 安装依赖

pip install langchain langchain-community langchain-openai chromadb fastembed streamlit

第 3 步 · 启动服务

streamlit run app.py

浏览器自动打开 http://localhost:8501，即可对知识库提问。
