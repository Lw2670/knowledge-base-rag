个人知识库问答

基于 RAG 技术，把你的 Markdown 笔记变成可对话的第二大脑。中文向量检索 + 大模型生成，答案带出处，不凭空编造。

进入问答系统 查看代码

启动服务后访问 localhost:8501

它是怎么工作的

四步链路，让笔记从静态文件变成可检索、可对话的知识。

文档加载

读取知识库里的 Markdown 笔记，保留原文结构。

智能分块

把长文切分成适合检索的小块，兼顾语义完整。

向量化入库

中文向量模型转成向量，存入本地 Chroma 库。

检索生成

提问 → 检索最相关笔记 → 大模型带出处回答。

技术栈

全部开源或可免费使用，本地运行，数据不外流。

LangChain Chroma BGE-small-zh 智谱 GLM-4-flash Streamlit

快速开始

三步即可运行自己的知识库问答服务。

  1. 1

    配置密钥

    把 config.py.example 复制为 config.py，填入智谱 API Key。

  2. 2

    安装依赖

    pip install langchain langchain-community langchain-openai chromadb fastembed streamlit
  3. 3

    启动服务

    streamlit run app.py

    浏览器自动打开 http://localhost:8501，即可对知识库提问。
